Add a strategy by creating bot/strategies/your_strategy.py and calling register(). It appears in the strategy list automatically.

# bot/strategies/my_strategy.py import pandas as pd from ..registry import register def my_strategy_run(df: pd.DataFrame, params: dict) -> dict: # signals are shifted by backtest.py, so no look-ahead here window = int(params["window"]) sma = df["close"].rolling(window).mean() positions = (df["close"] > sma).astype(float) return {"positions": positions, "extra_metrics": {}} register( name="my_strategy", description="Custom Moving Average Breakout Strategy", params=[{"name": "window", "label": "SMA Window", "min": 10, "max": 200, "step": 5, "default": 50}], run=my_strategy_run, )

How the backtest works

Execution. Signals act on the next bar (position = signal.shift(1)), the same timing you would have live.

Walk-forward. The regression model retrains on rolling windows of past data only. Cross-validation would leak future information.

Costs. Entry and exit both pay the selected slippage and fee. Compare every result against the buy-and-hold line before drawing conclusions.

Not investment advice. Educational project — no live trading.
