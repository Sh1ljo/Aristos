Build and backtest any new strategy by creating a single file in bot/strategies/your_strategy.py and calling register(). It will automatically populate the strategy cards and parameter sliders above without editing any frontend code!

# Minimal Strategy Template (bot/strategies/my_strategy.py) import pandas as pd from ..registry import register def my_strategy_run(df: pd.DataFrame, params: dict) -> dict: # Signals are applied to the next bar (shift 1) by backtest.py window = int(params["window"]) sma = df["close"].rolling(window).mean() positions = (df["close"] > sma).astype(float) return {"positions": positions, "extra_metrics": {}} register( name="my_strategy", description="Custom Moving Average Breakout Strategy", params=[{"name": "window", "label": "SMA Window", "min": 10, "max": 200, "step": 5, "default": 50}], run=my_strategy_run, )

Quantitative Trading Lab Guide

1. Zero Look-Ahead Bias: In live trading, you only execute orders at the open or close of tomorrow based on today's signal. The backtester guarantees this with position = signal.shift(1).

2. Walk-Forward AI: Standard cross-validation causes time leaks in financial data. Ridge regression uses rolling historical windows, training only on past bars to predict future days.

3. Capital Efficiency: Strategies that match buy-and-hold returns while staying in the market only 40-70% of the time expose you to far less tail risk and catastrophic drawdowns.
